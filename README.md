# GoGreen 🌱

A simple environmental awareness landing page designed to promote environmental protection, sustainability, and community involvement.

## Features

* Responsive landing page
* Environmental awareness sections
* Services and projects showcase
* Donation section
* Recent posts section
* Social media and newsletter section
* Responsive navigation

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
GoGreen/
├── images/
├── index.html
├── styles.css
├── script.js
└── .gitignore
```

## Getting Started

No installation or build process is required.

Simply open `index.html` in a web browser to view the website.
